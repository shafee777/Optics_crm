Optics CRM - Portable Windows App

This ZIP contains the Optics CRM desktop application and its local runtime.
It is for 64-bit Windows computers. Node.js, PostgreSQL, and an internet
connection are not required for the local shop features.

To use it:
1. Extract the complete ZIP to a normal folder on the target computer.
2. Open the extracted folder and run "Optics CRM.exe".
3. On first launch, create the shop and owner account in the setup window.

The ZIP does not contain customer records, passwords, or shop configuration.
Each computer keeps its own records in that Windows account's application data
folder. To move an existing shop, create a backup from the old computer and use
the app's restore option on the new computer. Keep backups somewhere separate
from the app folder.

Some optional actions, such as opening WhatsApp drafts, need internet access.
